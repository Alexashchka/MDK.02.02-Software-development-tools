Постановка задачи

Разработать отдельный модуль, получающий новости с сайта по Варианту.
Модуль должен быть реализован как консольное приложение, поскольку в последующем будет использоваться на сервере Ubuntu. При запуске приложения, необходимо указать начальные настройки, например: время обновления парсинга, период за который получаются новости (например неделя, месяц, год).
Разработанный модуль, необходимо загрузить в отдельную ветку PARSER.
При выполнении парсинга, необходимо использовать отладочные классы, которые записывают в файл состояния ответов от источников, и контент полученный в результате запроса.
В ветке PARSER должен находиться только проект для получения новостей и дополнительные связующие проекты (Common).

Реализовать отдельный модуль, для вывода информации на терминал. Приложение должно иметь графический интерфейс. Обмен данными с сервером должен происходить предпочтительно по TCP или UDP протоколу, или иным возможным способом. Разработанный модуль необходимо загрузить в ветку TERMINAL.
В ветке TERMINAL должен находиться только проект для отображения новостей и дополнительные связующие проекты (Common).

Данные между модулями необходимо передать в формате JSON или XML формате.
Итоговый результат, а именно два проекта полученных в результате слияния ветвей PARSER и TERMINAL, взаимодействующих друг с другом, необходимо поместить в ветку RELEASE.
